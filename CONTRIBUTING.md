# Contributing

The fastest way in is through CERATA. Open an issue, pick a generation from `CERATA_TARGETS.md` (or propose new
prey), and comment `/cerata consume ...`. The PR carries its hunt record, tests and trial records. A maintainer
plays it on a phone before merging.

Hand-written changes are welcome too: keep `npm test` green, document every new `kit.*` in `api/kit.md`, and add an
example under `examples/` that a four-year-old could play.
